Without cooperative participation, campaigns still run Electd with SOS data plus their own contacts. The cooperative is the upgrade path to L2-enhanced Arkansas records.

Contribution tiers

Local races

$200 one-time data contribution

Justice of the Peace and other races smaller than a county. Enhanced information for the relevant local geography.

Plus $149/mo if using Electd.

County organizations

$300 one-time data contribution

Enhanced information for the county to improve records and existing organizing systems.

Electd $149/mo is optional for counties that only want data.

State House and State Senate

$500 one-time data contribution

Plus $149 per month for campaigns using Electd.

Statewide campaigns

$700 one-time data contribution

Plus $149 per month for campaigns using Electd.

How the cooperative model works

If 50 counties participate:

50 counties × $300 = $15,000

That covers more than 60% of statewide acquisition.

If three statewide campaigns and ten local races participate:

3 statewide × $700 = $2,100

10 local × $200 = $2,000

Cooperative total so far:

$19,100

Ten State House or State Senate campaigns complete the purchase:

10 legislative × $500 = $5,000

Total: $24,100

Each participant pays a fraction of what it would cost to buy the statewide enhanced file alone.

What participants receive

Access to the portion of enhanced data appropriate for campaign, district, county, local geography, or statewide jurisdiction—subject to final vendor licensing.

  • Improve voter-contact records
  • Update internal databases
  • Strengthen VAN matching
  • Build better call, text, email, and mail lists
  • Reduce wasted communication spend
  • Preserve campaign-specific relationships

Founding participation is conditional

Reduced cooperative pricing is available only if enough organizations participate to fund acquisition.

The statewide file will not be purchased—and discounted pricing will not be finalized—unless participants collectively cover the acquisition cost.
